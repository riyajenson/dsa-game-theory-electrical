# Project agent instructions

Build a local, pixel-art, single-player sensor-network strategy RPG before multiplayer or cloud work. The C++ simulation is authoritative for actions, routing, energy, reputation, delivery, scoring, and seeded replay.

- Inspect branches, working tree, relevant code, docs, tests, and playable behavior before editing. Preserve unrelated changes.
- Work sequentially without subagents. Scope one playable milestone and document its rules and acceptance criteria.
- Keep the existing analysis dashboard accessible. Make deliberate rule differences from its batch simulation explicit.
- Use original or licensed art; document provenance. Show action feedback and route, energy, reputation, and packet effects.
- Run focused native/API checks, relevant full checks, and inspect desktop and narrow layouts. Report actual results and risks.
- Make small descriptive local commits only after verification. Do not push, merge, open a PR, deploy, provision cloud resources, spend money, or add secrets without explicit user direction.
- Read `skill.md` and the active milestone design/plan when working in this repository. More specific user instructions take precedence.
