# Phase Roadmap

## Main Branch

The `main` branch contains only the project overview README.

## Phase 1: Game Theory Foundation

Status: core implemented, documentation polish in progress.

Focus:

- Game-theory decision engine
- Cooperative vs selfish behavior
- Utility calculation
- Reputation update
- Selfish node detection
- Demo output

## Phase 2: Graph and Routing Engine

Focus:

- Weighted graph representation
- Sensor nodes as vertices
- Communication links as edges
- Dijkstra's algorithm with priority queue
- Energy-aware route selection

## Phase 3: DP Energy Planner

Focus:

- Repeated decision optimization
- State representation using round and energy
- Compare greedy decision-making with DP planning

## Phase 4: Simulation Metrics

Focus:

- Packet delivery ratio
- Average residual energy
- Network lifetime
- Selfish event count
- Strategy comparison tables

## Phase 5: Dashboard

Focus:

- Visualize node states
- Show routes and energy levels
- Display metric charts
- Highlight suspicious nodes

## Phase 6: Final Polish

Focus:

- Final report
- Screenshots
- Result analysis
- Code cleanup
- Presentation support
